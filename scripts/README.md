# Repomedic Helper Scripts

Helper scripts to streamline development, testing, and fixture evaluation.

| Script | Platform | Description |
| :--- | :--- | :--- |
| `dev.ps1` | Windows (PowerShell) | Checks dependencies and boots the Vite frontend dashboard |
| `dev.sh` | Linux / macOS (Bash) | Boots local development servers with graceful termination |

## Usage

### Windows (PowerShell)
```powershell
.\scripts\dev.ps1
```

### Linux / macOS (Bash)
```bash
chmod +x scripts/dev.sh
./scripts/dev.sh
```
